KYM: A Multi-Agent System for Complex Knowledge Retrieval, Synthesis and Generation

Industry

KYM is a proprietary multi-agent system designed for complex engineering tasks over dense aerospace and industrial documentation.

  • Technical Core: built on an Agentic Loop for task decomposition and tool execution, it features an advanced hybrid RAG pipeline: Multi-Query + HyDE for expansion, parallel vector and BM25 search, merged via RRF Fusion and optimized by a final Reranking step.
  • Other Use Cases: automates Technical Documentation Generation through iterative agent loops, and drives a Failure Segmentation Agent using specialized tool implementations to parse logs and isolate complex system faults.
  • Confidentiality: strictly confidential. All code, architecture, and data are the exclusive property of the company.

Performance Analysis of a Tiny Diffusion Model Implementation

Academic

Diffusion models are powerful generative models but are often associated with high computational costs due to their iterative structure. This report presents a performance analysis of tiny-diffusion, a minimal PyTorch implementation of probabilistic diffusion models operating on low-dimensional 2D datasets. By combining Python-level and system-level profiling (cProfile, Hyperfine) with framework-level profiling (PyTorch Profiler), we identify computational bottlenecks during training. The goal is to characterize the performance structure of diffusion models in a controlled setting and to extract actionable optimization insights.

📄 Report (PDF) GitHub ↗

Reinforcement Learning Challenge: Deep Q-Learning Agent for Sailing Navigation

Academic

Design, implementation, and training of a Deep Q-Network (DQN) agent for autonomous sailing navigation in dynamic wind fields. The agent must navigate from a starting position to a goal location while optimally exploiting wind patterns. We describe our architectural choices, feature engineering approach, training methodology, and provide a detailed performance analysis.
